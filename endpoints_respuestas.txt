POST http://localhost:3000/auth/register
------------------------------------------------------------------------------
Registrar nuevo usuario (PROFESOR o PADRE). ADMIN solo desde DB.

Body (JSON):
{
  "nombres": "string",
  "apellidos": "string",
  "carnet": "string",
  "password": "string",
  "rol": "PROFESOR" | "PADRE",
  "correo": "string (opcional)",
  "celular": "string (opcional)",
  "username": "string (opcional, usa carnet si no se envía)"
}

Respuesta exitosa (201):
{
  "success": true,
  "data": {
    "mensaje": "Usuario registrado exitosamente",
    "id_persona": "uuid",
    "username": "string",
    "rol": "PROFESOR | PADRE"
  }
}

Errores:
- 400: Faltan campos obligatorios
- 409: Carnet o username ya existe

carnet,nota_ser,nota_saber,nota_hacer,nota_decidir,autoevaluacion

id_estudiante,nota_ser,nota_saber,nota_hacer,nota_decidir,autoevaluacion

carnet,nota_ser,nota_saber,nota_hacer,nota_decidir,autoevaluacion

EMP002,18,22,19,14,8

    "mensaje": "Exito. Se procesaron 2 filas y se guardaron 2 notas",
    "procesadas": 2,
    "guardadas": 2,
    "omitidas": 0
  }
}

- 403: El profesor no tiene permiso sobre esta carga

================================================================================
                           RESUMEN POR ROL
================================================================================

ADMIN (accesso total):
  - AUTH: register, login, perfil
  - USERS: todas las operaciones (estudiantes, padres, profesores, vincular)
  - ACADEMIC: CRUD completo (cursos, materias, cargas)
  - ENROLLMENTS: CRUD completo
  - GRADES: upload, ver notas por estudiante/curso/carga
  - COMMUNICATIONS: ver comunicados por estudiante

PROFESOR:
  - AUTH: login, perfil
  - USERS: ver estudiantes, ver estudiantes por ID
  - ACADEMIC: ver cursos, materias, cargas propias
  - ENROLLMENTS: ver inscripciones
  - GRADES: upload notas (solo de sus cargas), ver notas
  - COMMUNICATIONS: enviar comunicados, ver por estudiante

PADRE:
  - AUTH: login, perfil
  - USERS: ver estudiantes (hijos vinculados)
  - ENROLLMENTS: ver inscripciones de sus hijos
  - GRADES: ver notas de sus hijos
  - COMMUNICATIONS: ver mis comunicados, marcar como leído

================================================================================
                              NOTAS IMPORTANTES
================================================================================

1. Todos los endpoints (excepto /auth/register y /auth/login) requieren:
   Headers: Authorization: Bearer <jwt_token>

2. El token JWT contiene:
   {
     "sub": "id_usuario",
     "rol": "ADMIN | PROFESOR | PADRE",
     "id_persona": "uuid"
   }

3. Los endpoints protegidos con @Roles() verifican el rol del token.

4. Las respuestas siguen el formato:
   { "success": true, "data": {...}, "message"?: "..." }

5. Los errores devuelven:
   { "success": false, "statusCode": 400, "message": "...", "error": "..." }

6. Para paginación usar ?page=1&limit=20 en endpoints que lo soporten.
